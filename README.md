# Code_Raginii

A Chrome extension that automatically syncs accepted LeetCode solutions to GitHub.

- **Created by:** Ragini
- **Official repository:** [https://github.com/Ragini-telange/Code_Raginii_Extension](https://github.com/Ragini-telange/Code_Raginii_Extension)

---

## Features

- **Automatically sync accepted LeetCode solutions** directly to GitHub.
- **Upload solutions to a selected GitHub repository** with clean problem organization.
- **Prevent duplicate uploads** on page reloads, re-submissions, or repeat sessions.
- **Maintain a README** with a formatted, sorted table linking to all solved problems.

---

## Installation

1. **Download or clone this repository**:
   ```bash
   git clone https://github.com/Ragini-telange/Code_Raginii_Extension.git
   ```
2. **Extract the project** if downloaded as a ZIP.
3. Open `chrome://extensions` in Google Chrome.
4. Enable **Developer mode** (toggle located in the top-right corner).
5. Click **Load unpacked** and select the project folder (`Code_Raginii_Extension`).

---

## How to Use

1. **Connect GitHub**:
   - Click the **Code_Raginii** icon in the Chrome toolbar.
   - Enter a GitHub Personal Access Token (classic with `repo` scope or fine-grained token with Contents read & write).
   - Click **Connect GitHub**.
2. **Choose Repository**:
   - Select your target repository or click **Create on GitHub** to initialize one automatically.
3. **Solve on LeetCode**:
   - Open any LeetCode problem in Python, C++, Java, JavaScript, TypeScript, C, or SQL.
   - Click **Submit**. When **Accepted**, Code_Raginii automatically commits your solution to GitHub with zero annoying popups.
